# ความตรงกับ design system

## ก่อนแตะค่าเชิงภาพใดๆ

ต้องเปิดไฟล์ token ก่อนเสมอ (`tailwind.config.*`, `theme.*`, `tokens.*`)
ห้ามเดาค่าจากชื่อ variant หรือจากความทรงจำ

## ห้าม hardcode

- ห้ามใส่ค่า hex (`#2563eb`) ลงใน component โดยตรง
- ห้ามใส่ค่า px ดิบสำหรับ spacing ที่มี scale อยู่แล้ว
- ต้องอ้างผ่านชื่อ token เช่น `bg-brand-600` ไม่ใช่ `bg-[#2563eb]`

ถ้าค่าที่ต้องการยังไม่มีใน token — ให้รายงานผู้ใช้ว่าต้องเพิ่ม token ใหม่ก่อน
ห้ามแก้ไฟล์ token เองโดยไม่ได้รับคำสั่ง

## ขอบเขตของงาน UI

งาน "แก้สีปุ่มหน้าเดียว" ต้องจบที่ไฟล์หน้านั้น + component ที่เกี่ยวข้องโดยตรงเท่านั้น
ห้ามไล่แก้ component อื่นที่ใช้ variant เดียวกัน แม้จะดูไม่สอดคล้องกัน — ให้รายงานแทน

## ตรวจก่อนบอกว่าเสร็จ

- ค่าที่ใส่มีอยู่จริงในไฟล์ token
- ไม่มี hex หลุดเข้าไปใน diff
- จำนวนไฟล์ที่แก้สมเหตุสมผลกับขนาดของงาน
