What Context Engineering and Agent Skills are

Before the results, here is the background: what these two terms mean, how they work, where they come from, and why we wanted to measure them.

Start with the word "context"

An AI such as Claude or ChatGPT does not remember anything between tasks. Every time it answers or acts, it only knows what is in front of it at that moment. This is called its context, and it includes everything sent to the model: the system instructions, the user’s instructions, files it has opened, the output of commands it has run, and the conversation so far.

As a result, if a team rule is not in the context, the AI does not know the rule exists, even if everyone on the team knows it well. Everything on this page comes back to one question: what to put into the context, when, and how much.

From Prompt Engineering to Context Engineering

When people first started using ChatGPT, what everyone cared about was how to write the instruction to get a good answer. This was called prompt engineering.

Once AI became an agent that can work through many steps on its own, reading files, running commands and editing code, the context was no longer just the instruction we typed. It holds everything that flows in along the way: documents, test results and messages from tools. In mid 2025 people in the field began calling this work context engineering, and Anthropic describes it as choosing and managing what is in the context so that it is just right at each point while the model works.

Why not put everything in?Context has a limited size, and the more you put in, the less accurately the model can pull out what it needs. Anthropic calls this context rot and compares it to an "attention budget" that every word uses up a little of. So the aim of context engineering is not to put in as much as possible, but only what is needed, and to load the rest when it is needed.

Rule files, the first way teams passed on rules

The simplest way is to write all the rules in one file and have the tool load it into the context every time a task starts. Each tool has its own file name, such as CLAUDE.md for Claude Code and .cursorrules for Cursor. In August 2025 AGENTS.md appeared as a shared format that many tools can read.

The upside is that it is easy to write and maintain, and you can be sure the AI sees every rule. The downside is that every rule takes up context space all the time, even rules unrelated to the task at hand. For example, while editing a web page the AI still has to read the billing rules.

Agent Skills, opened when needed

In October 2025 Anthropic launched Agent Skills, which applies the "load when needed" idea of context engineering to knowledge and rules. A skill is a folder containing a SKILL.md file. The top of the file holds a name and a short description of when to use it, the rest is the full content, and there may be other supporting files. The AI sees the information in three layers.

  1. Name and descriptionThe AI sees these for every skill from the start, and uses them to decide which skill relates to the task
  2. Full content of SKILL.mdThe AI opens it when it sees that the task matches the description
  3. Supporting filesThe AI opens these only when the full content tells it to look

This idea is called progressive disclosure: revealing only as much information as is needed. In December 2025 Anthropic made Agent Skills an open standard at agentskills.io, so the same skills can be used with other tools.

Timeline

  1. Early ChatGPT daysPeople focused on how to write instructions that get good answers, which became known as prompt engineering
  2. Jun 2025Tobi Lütke (Shopify) and Andrej Karpathy suggested calling this work context engineering instead, because what really matters is all the information the model sees, not just the wording of the instruction
  3. Aug 2025AGENTS.md appeared as a shared rule file format that many tools can read, instead of each tool having its own file
  4. 29 Sep 2025Anthropic published an article explaining context engineering systematically and pointing out that context is a limited resource
  5. 16 Oct 2025Anthropic launched Agent Skills, which let an agent open knowledge or rules only when a task needs them
  6. 18 Dec 2025Agent Skills became an open standard at agentskills.io, so other tools can use the same format
  7. Early 2026The first studies measured how much skills help agents, but mostly compared them with having no skills
  8. Oct 2026Our work, which compares a single file directly with Skills, with every rule identical

Why we measured this

Agent Skills rests on the belief that if unrelated rules do not get in the way, the AI will follow the relevant rules better. That sounds reasonable, but there is a risk on the other side: the AI may not open a skill it should open, and so never see an important rule.

Studies published in early 2026 measured whether "having skills" beats "having no skills". As far as we could find, nobody had compared a single file directly with Skills while keeping every rule identical, and measured whether the AI really broke the rules based on what it did to the system.
