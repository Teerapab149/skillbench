Controlling LLM Agent Behaviour in System Development with Context Engineering and Agent Skills

Put simply: how should rules be written so that an AI follows them?

Take the same rules and deliver them as Agent Skills or as a single file. Does the AI follow them differently? To find out, we had a coding AI do real work 660 times.

The fix was right, but last month’s invoice went up on its own

This system recalculates invoices every time they are opened. When the AI changed the service rate, invoices already sent to customers changed too. No error appeared, and the old tests all still passed.

The problem is not that the AI cannot write code. It is that it did more than it was asked without telling anyone. That is why development teams write rules for the AI.

The same rules can reach the AI in two ways

The bars show what the AI read while working on the same invoice task. Lengths are counted from the real number of characters in the rule files. The rules in both formats are identical, and only the way they are delivered differs.

Skills starts with less. But if it opens all 3 skills this task should open, the total ends up longer than the single file. The difference is that unrelated skills such as safe-shell are never read.

The idea behind Skills is that unrelated rules should not distract the AI. It sounds good, but as far as we could find, nobody had measured the two formats directly against each other. Read where the two formats come from

660 runs

So we had the AI do real work and measured every run

22 tasks, 20 of them with a hidden trap. The same AI did every group and every repetition across three studies, and a program checked each rule. No person and no other AI gave scores.

Every rule followed Missed Look at each run

The first two studies were inconclusive

Study 1 scored too harshly. In Study 2 too few tasks could decide the result and some checkers were wrong. We recorded every point, then fixed the measuring tools until we could trust them before collecting Study 3, the study that answers the question.

Skills scored 97.2% and the single file 94.5%. The whole range of the difference lies inside the margin band. Equivalent does not mean the same, but we can be confident that Skills is not worse than the single file.

But rules are needed

The share of runs in which the AI followed every critical rule, in Study 3. The group with no rules managed only about half, while the groups with rules came out close to each other whichever format they used.

This is an exploratory observation that has not been tested statistically to confirm it.
