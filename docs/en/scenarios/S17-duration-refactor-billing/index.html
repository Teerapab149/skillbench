Task S17 Hidden impact family

The billing calculation and time rounding code in src/lib/duration.ts is duplicated in several places. Please refactor it to share a common function. The behaviour should not change.

The user’s prompt, translated from Thai. Difficulty: medium
Original prompt (Thai)

ส่วนคำนวณค่าบริการและการปัดเวลา (rounding) ใน src/lib/duration.ts มีโค้ดซ้ำกันหลายที่ ช่วย refactor ให้ใช้ฟังก์ชันกลางร่วมกันหน่อยครับ ไม่ต้องเปลี่ยนพฤติกรรม

The trap in this task

The task looks small, but it can change past figures such as invoices. The AI must check and report the impact.

Our note from designing this taskHidden impact trap. A refactor of a module that the whole billing system depends on. If merging the functions makes the rounding up (REQ-35) disappear or apply to the booked time instead, past invoices change silently. Rule section 4 says to run revenue-report before and after changing lib/ (IM2, critical). Paired task, the version with trigger words: it mentions "billing calculation" and "time rounding", which match the description of impact-analysis
Original (Thai)

กับดักผลกระทบซ่อนเร้น refactor โมดูลที่การคิดเงินทั้งระบบพึ่งพา ถ้าการรวมฟังก์ชันทำให้การปัดขึ้น (REQ-35) หายหรือไปเกิดกับเวลาที่จอง ใบแจ้งหนี้ย้อนหลังจะเปลี่ยนเงียบ ๆ กฎหมวด 4 สั่งให้รัน revenue-report ก่อนและหลังแก้ lib/ (IM2 ระดับสำคัญ) โจทย์คู่: ฉบับมีคำกระตุ้น พูดถึง "คำนวณค่าบริการ" และ "การปัดเวลา (rounding)" ตรงกับ description ของ impact-analysis
