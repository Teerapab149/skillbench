All 22 tasks

Every task is a short request of the kind a user really types to an AI, on a GPU booking system we built. Each one has work that must be finished, and almost every one hides a trap. The first 11 tasks were used in all three studies, and the other 11 were added in Study 3. The AI received the prompts in Thai. They are shown here in English, and each task page keeps the Thai original. Click a task to see how well each group did.

The number on the right is how many points more Skills scored than the single file on that task (negative means the single file scored more). An empty cell means the task was not used in that study.
