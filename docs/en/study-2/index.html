Study 2 of 3

Measuring again with proportional scoring

This time runs were scored by the share of rules followed. Skills again scored higher, but we still could not conclude anything, because only 5 tasks could decide the result and some of our checkers were still wrong.

Inconclusive 11 tasks, 4 repetitions each, 176 runs in total, data collection finished 19 Sep 2026

On this page

  1. Result
  2. Why this study was inconclusive
  3. What changed next
  4. Full numbers for examiners

Result

Skills scored 61.5% and the single file 50.5%, a difference of +11.0 points

Skills scored higher, but there is too little data to tell whether the difference is real or just chance (p = 0.250). So the result is inconclusive, which does not mean the two formats are equal.

Skills always loaded differs from Skills by −8.8 points. But the plan allowed this to be tested only if the main result passed, so it was not tested.

Why this study was inconclusive

  1. Only 5 tasks could decide the result, the same as before. The new scoring made the numbers finer, but not enough to draw a conclusion.
  2. Of the 6 tied tasks, 3 were tied because our checker was wrong, not because the AI really did equally well.
  3. An AI that stopped to ask, as the rules told it to, was counted as not finishing the task. The groups with rules were penalised for being careful.
  4. Our own plan said we should add tasks rather than repetitions, but this time we did not. We record this openly as a mistake.

What changed in the next study

For the next study we increased the tasks to 22, fixed the faulty checkers, sent a reply to an AI that stopped to ask so it could carry on, checked the measuring tools over several rounds before the real collection, and decided in advance how small a difference counts as equivalent.

Finishing the task versus following the rules

The main score combines two things in one number: whether the task was finished, and how well the rules were followed once it was. Looked at separately, the two go in different directions.

Table 4 Task finished rate, and rule following when the task was finished
GroupTask finishedRules followed when finished
A0 No rules75.0%0.895
A1 Single file52.3%0.967
A2 Agent Skills63.6%0.967
A5 Skills, always loaded54.5%0.967

The groups with rules all followed the rules at a similar level, about 0.967, when the task was finished. But the group with no rules finished the task most often. Part of the reason is that the AI with rules stopped to ask when the requirements were unclear, and stopping to ask was counted as not finished. This is why in Study 3 we sent a reply to an AI that stopped to ask so it could carry on.

This table was not tested statistically and was not in the plan written beforehand, so it is an exploratory observation, not a conclusion.
