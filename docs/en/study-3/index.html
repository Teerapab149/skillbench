Fixing the measuring tools and measuring once more

This time we fixed the measuring tools until we could trust them, then had the AI do 22 tasks, 3 times each. Skills and the single file were equivalent in how well the AI followed the rules. The difference stayed inside the margin we set before starting.

Equivalent 22 tasks, 3 repetitions each, 264 runs in total, data collection finished 10 Oct 2026

On this page

  1. Result
  2. What else we saw
  3. Full numbers for examiners

Result

Skills scored 97.2% and the single file 94.5%, a difference of +2.8 points

Before starting, we set the rule that if the two formats differ by no more than ±12.5 points, which is roughly one missed critical rule per task, they count as equivalent. The whole range of the result fell inside that margin, so we concluded Equivalent

How to read this Equivalent does not mean exactly the same. And because the single file already scored 94.5%, Skills could lead by at most 5.5 points. What we can really be confident of is that Skills is not worse than the single file.

We also recounted in two other ways, fixing the checkers we found to be wrong and removing the problem tasks. The result was still equivalent (rows SA-1 and SA-2 in the figure).

Whether "opening one skill at a time" matters needs a comparison of Skills with Skills always loaded. Our plan allowed that test only if the main question found a difference. Since the main result was equivalent, it was not tested. The figure you see, +2.0 points, is for reference only and supports no conclusion.

What else we saw

Everything in this section is exploratory: things we observed that are not part of the main question tested under the plan.

Having rules or not made a bigger difference

The largest difference was not between the two formats but between having rules and having none. The AI with no rules followed every critical rule in only 53.0% of runs, edited files outside the task more often, and missed the rule about past invoices 18 of 72 times, almost always by not checking or not saying so. The groups with rules missed it no more than 2 times.

But we cannot yet tell whether the improvement comes from what the rules say or just from giving the AI more text to read, because this study had no group that got text of the same length that was not rules.

Skills cost a little less

Skills cost $0.095 less per task than the single file on average, about 10%, and was about 30 seconds faster. But the Skills runs were also shorter, so we cannot yet say whether it was cheaper because skills are opened one at a time.

Skill descriptions matter a lot

The AI opened 2.2 of 4 skills per task on average, and opened all of them in only 1 runs. Some skills were opened when not needed and some were not opened when they should have been (accuracy between 0.74 and 0.99 out of 1). If the descriptions are poorly written, the rules do not reach the AI.

Why we sent a reply to an AI that stopped to ask

The AI with rules often stopped to ask before acting, which is a good thing. But counting only the first turn, these tasks would be marked as not finished. So we sent the same message back every time, letting it carry on once. 22 of 25 runs went on to finish. The AI with no rules did not finish 5 times, and none of those came back to finish. Counting only the first turn, the difference would be +2.4 points, but the range where the true value probably lies is very wide, from −8.0 to +13.8.
