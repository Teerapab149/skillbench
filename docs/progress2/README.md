โฟลเดอร์นี้คือ**สำเนาสำหรับเผยแพร่** ของ [`progress2/explorer/index.html`](../../progress2/explorer/index.html)

## เปิดยังไง

| วิธี | ทำยังไง |
|---|---|
| **ในเครื่อง** | ดับเบิลคลิก `index.html` — ไม่ต้องมีเน็ต ไม่ต้องรัน server ไม่ต้องล็อกอิน |
| **ส่งให้คนอื่น** | แนบไฟล์ `index.html` ไฟล์เดียว ข้อมูลฝังอยู่ข้างในหมดแล้ว |
| **เปิดจากลิงก์** | ดูหัวข้อ GitHub Pages ข้างล่าง |

ลิงก์ไปหัวข้อใดหัวข้อหนึ่งได้โดยตรงด้วย hash ท้าย URL เช่น `…/progress2/#why`
สำหรับกระโดดไปหัวข้อ “ทำไมยังฟันธงไม่ได้”

## เผยแพร่ด้วย GitHub Pages

1. push โค้ดขึ้น branch `main` ให้เรียบร้อยก่อน
2. เปิด repo บน GitHub → **Settings** → **Pages**
3. หัวข้อ **Build and deployment** → **Source** เลือก **Deploy from a branch**
4. **Branch** เลือก `main` และโฟลเดอร์เลือก **`/docs`** → กด **Save**
5. รอสักครู่ แล้วเปิด

```
https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/progress2/
```

ไฟล์ `docs/.nojekyll` มีไว้บอก GitHub Pages ว่าไม่ต้องประมวลผลด้วย Jekyll
**อย่าลบ** ไม่งั้นบางไฟล์อาจถูกข้าม

> ⚠️ **repo นี้เป็นสาธารณะหรือเปล่า** — GitHub Pages ของบัญชีแบบฟรีจะเผยแพร่ได้เฉพาะ repo สาธารณะ
> ถ้า repo ยังเป็นส่วนตัวและยังไม่อยากเปิด ให้ส่งไฟล์ `index.html` ให้อาจารย์ตรง ๆ แทน ได้ผลเหมือนกัน

## ห้ามแก้ไฟล์ในโฟลเดอร์นี้

`index.html` ที่นี่เป็น**ผลลัพธ์** แก้แล้วจะหายตอน build รอบถัดไป

| จะแก้อะไร | แก้ที่ไหน |
|---|---|
| ข้อความ · หน้าตา · การทำงานของหน้าเว็บ | `slides-images/src/explorer.html` |
| ตัวเลขและข้อมูล | **ไม่ต้องแก้** มันอ่านจาก `results/` · `results-study2/` · `arms/**` · `scenarios/` เอง |

สร้างใหม่ทั้งสองที่ด้วยคำสั่งเดียว

```bash
node slides-images/src/make-explorer-data.mjs
```

คำสั่งนี้เขียนทั้ง `progress2/explorer/index.html` และ `docs/progress2/index.html`
พร้อมกันเสมอ เพื่อไม่ให้เว็บที่เผยแพร่ไปคนละเรื่องกับไฟล์ในโปรเจกต์
