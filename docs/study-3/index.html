มีกฎกับไม่มีกฎ (เชิงสำรวจ)

ความต่างที่ใหญ่ที่สุดในข้อมูลไม่ได้อยู่ระหว่างรูปแบบของกฎ แต่อยู่ระหว่างมีกฎกับไม่มีกฎ เอเจนต์ที่ไม่ได้รับกฎแก้ไฟล์นอกขอบเขตบ่อยกว่า และไม่ตรวจหรือไม่รายงานผลกระทบต่อใบแจ้งหนี้ย้อนหลังบ่อยกว่ามาก

การที่ยอดย้อนหลังเปลี่ยนจริงเกิดน้อยมากในทุกกลุ่ม สิ่งที่ A0 พลาดเกือบทั้งหมดคือไม่วัดหรือไม่บอก แถว "ไม่ทำเกินสั่ง" ตกส่วนใหญ่ที่ S05 GP1 ซึ่งพบว่าตัวตรวจจับผิด จึงยังประเมินไม่ได้

ข้อควรระวังการเทียบกับ A0 ไม่ใช่ผลหลัก ไม่ได้ปรับการทดสอบหลายครั้ง และชุดนี้ไม่มีกลุ่มที่มีข้อความยาวเท่ากันแต่ไม่ใช่กฎ จึงแยกไม่ได้ว่าที่ดีขึ้นมาจากเนื้อหาของกฎหรือจากการมีข้อความเพิ่มในบริบท

ต้นทุนและการเปิด skill (เชิงสำรวจ)

Skills ใช้ต้นทุนเทียบเท่า API ต่ำกว่าไฟล์เดียวราว 9% และใช้เวลาน้อยกว่าราว 32 วินาทีต่องาน แต่งานของ A2 ก็สั้นกว่าด้วย จึงยังบอกไม่ได้ว่าส่วนต่างมาจากการโหลดเฉพาะส่วน

A2 เปิด skill เฉลี่ย 2.21 จาก 4 ชุดต่อ run และมีเพียง 1 run ที่เปิดครบ ความแม่นของการเปิด (F1) อยู่ระหว่าง 0.74 ถึง 0.99 คำอธิบายของ skill จึงเป็นตัวกำหนดว่ากฎจะไปถึงเอเจนต์หรือไม่

รอบตอบกลับ

ณ จบรอบแรก ผลต่างคือ +2.4 จุด แต่ช่วงความเชื่อมั่น 95% กว้างถึง [−8.0, +13.8] เพราะเอเจนต์ที่มีกฎหลาย run หยุดถามก่อนลงมือ หลังส่งข้อความตอบกลับหนึ่งครั้ง run เหล่านี้ทำต่อจนสำเร็จ 22 จาก 25 run ส่วน A0 ที่ไม่สำเร็จ 5 run ไม่มี run ใดกลับมาสำเร็จ
