The AI changed the price correctly, and last month's invoice changed with it

Scenario S09 from study 3. The rate is from the real task, the hours are illustrative.

[Speaker 1, 1:00] AI coding agents like Claude Code, Copilot and Cursor are very good at writing code now. The real problem teams face is not that the agent cannot code. It is that the agent does things nobody asked for, and does not say so. This is a real task from our experiment. The user asks the agent to raise the price of a GPU machine. The agent changes the price correctly. But the system recalculates invoices from the current price, so last month's invoice also changes. In a real business, that is a serious problem. So teams give the agent rules. For example: change only what was asked, never delete data, and check the impact before touching billing.
