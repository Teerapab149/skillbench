[Speaker 1, 1:00] Our main question: if two rule sets contain exactly the same 47 obligations, does packaging them as Skills instead of one file change how well the agent follows them? We used four groups. A0 gets no rules, as a baseline. A1 and A2 are the main pair. A5 has the same content as A2 but in one file that is always loaded. It tells us whether a difference comes from the loading mechanism or from the wording. Importantly, we locked the decision rule on GitHub before collecting any data.
