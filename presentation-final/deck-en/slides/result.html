[Speaker 2, 1:30, the most important slide] Here is the main result. Skills scored 97.2, the single file 94.5. A difference of 2.8 points. Does 2.8 points matter? Before collecting data, we said that a difference within 12.5 points, which is about one critical rule missed per task, counts as equivalent. The green band is that margin. The blue line is where the true difference probably lies. The whole line is inside the band, so by our rule the result is: equivalent. But read it carefully. Equivalent does not mean identical. And because the single file already scored 94.5, Skills could lead by at most 5.5 points. What the data really confirms is that Skills is not worse than a single file. The lower bound is minus 0.1, almost exactly zero. When we split the 2.8 points, almost all of it comes from two runs where the single-file agent did not finish the task. When the task was finished, both formats followed the rules almost equally well. Never say "the same" or "Skills is better".
