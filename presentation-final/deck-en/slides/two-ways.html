[Speaker 1, 1:00] There are two main ways to give an agent rules. The first is one file, like CLAUDE.md on the left. The agent reads every rule, every time it starts. The second is Agent Skills, released by Anthropic in 2025. The rules are split into small packages. At the start the agent sees only a one-line description of each package, and it opens the full text only when the task matches. The idea behind Skills is that rules that do not matter for this task should not clutter the context, so the agent should follow the relevant rules better. That sounds reasonable. But as far as we could find, nobody had measured the two formats side by side with the same rule content. So we did.
