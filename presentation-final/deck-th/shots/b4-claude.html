b4-claude

Claude มีสองบทบาทที่แยกกัน คะแนนมาจากโปรแกรมที่ตรวจย้อนได้ แต่ความเสี่ยงเรื่องอคติยังไม่หมด

สิ่งที่เราทดลอง Claude Sonnet 5 ผ่าน Claude Code ทั้งหมด 264 ครั้ง

เครื่องมือช่วยงานของเรา ร่างแผนและโจทย์ เขียนโค้ดระบบวัด เฝ้าการรัน ตรวจทานแผนด้วย session แยก ประเมินว่ารอบที่ 4 จะช่วยแค่ไหน ช่วยวิเคราะห์ และช่วยเรียบเรียงเล่ม

สิ่งที่กันอคติ ตัวตรวจเป็นโปรแกรม แผนล็อกด้วย git tag ก่อนเก็บข้อมูล ตรวจย้อนได้ทุก commit และการตัดสินใจหลักเป็นของเรา

สิ่งที่ยังกันไม่ได้ การตรวจทานแผนใช้ Claude อีก session และไม่มีบุคคลที่สามยืนยันว่าเราไม่ได้ดูผลแยกกลุ่มก่อน

สำรอง B4 บทบาทของ Claude (คำนำ และหัวข้อ 6.4 ข้อ 3 ในเล่ม)
