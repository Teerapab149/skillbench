Claude มีสองบทบาทที่แยกกัน
คะแนนมาจากโปรแกรม แต่ความเสี่ยงเรื่องอคติยังไม่หมด

สิ่งที่เราทดลองClaude Sonnet 5 ผ่าน Claude Code ทั้งหมด 264 ครั้ง
เครื่องมือช่วยงานของเราร่างแผนและโจทย์ เขียนโค้ดระบบวัด เฝ้าการรัน ตรวจทานแผนด้วย session แยก ประเมินว่ารอบที่ 4 จะช่วยแค่ไหน ช่วยวิเคราะห์ และช่วยเรียบเรียงเล่ม
สิ่งที่กันอคติตัวตรวจเป็นโปรแกรม แผนล็อกด้วย git tag ก่อนเก็บข้อมูล ตรวจย้อนได้ทุก commit และการตัดสินใจหลักเป็นของเรา
สิ่งที่ยังกันไม่ได้การตรวจทานแผนใช้ Claude อีก session และไม่มีบุคคลที่สามยืนยันว่าเราไม่ได้ดูผลแยกกลุ่มก่อน

สำรอง B4 บทบาทของ Claude (คำนำ และหัวข้อ 6.4 ข้อ 3 ในเล่ม)

ตอบเมื่อถูกถามว่า "ใช้ Claude ช่วยทำวิจัยที่ทดลอง Claude ไม่ลำเอียงเหรอ" ระบุเป็นข้อจำกัดไว้ในหัวข้อ 6.4 ข้อ 3 และในคำนำ ยอมรับว่าขจัดความเสี่ยงนี้ไม่ได้ทั้งหมด สิ่งที่ทำได้คือทำให้ทุกขั้นตรวจย้อนได้
