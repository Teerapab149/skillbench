ในเงื่อนไขที่เราทดลอง ครึ่งหลังเป็นข้อสังเกตเพิ่ม

สแกนเพื่อดูกฎของแต่ละกลุ่ม โจทย์ทั้ง 22 ข้อ บันทึกการทำงานทุกครั้ง รายงานฉบับเต็ม และโค้ดบน GitHub

[คนที่ 2, 0:45] สรุปนะครับ การใช้ไฟล์เดียวหรือ Agent Skills ให้ผลการทำตามกฎที่เทียบเท่ากัน ในเงื่อนไขที่เราทดลอง จะใช้แบบไหนก็ได้ แต่ควรมีกฎให้ AI เสมอ เพื่อป้องกันความผิดพลาดแบบเรื่องใบแจ้งหนี้ที่เล่าไป ครึ่งแรกคือผลหลักที่ทดสอบตามแผน ส่วนครึ่งหลังเป็นข้อสังเกตเพิ่ม หากท่านใดสนใจอยากดูลึกกว่านี้ ทั้งกฎที่ใส่ให้ AI แต่ละกลุ่ม โจทย์ทั้ง 22 ข้อกับกฎของแต่ละโจทย์ และการทำงานของ AI ในแต่ละรอบ เราบันทึกไว้ทั้งหมด เข้าไปดูได้ในเว็บไซต์ตาม QR code นี้เลยครับ ส่วนท้ายเว็บไซต์มีรายงานฉบับปัจจุบัน และลิงก์ GitHub ให้ดูต่อได้ สำหรับการนำเสนอสัมมนาของกลุ่มเราก็ขอจบเพียงเท่านี้ หากท่านใดมีคำถาม ถามได้เลยครับ ขอบคุณครับ
