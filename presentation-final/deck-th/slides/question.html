คำถามของเรา: กฎชุดเดียวกัน เขียนสองแบบนี้
AI ทำตามต่างกันไหม

กลุ่ม AIได้กฎแบบไหนมีไว้ทำอะไร
ไม่มีกฎไม่ได้กฎเลยจุดเริ่มต้นไว้เทียบ
ไฟล์เดียวกฎ 20 ข้อในไฟล์เดียวคู่หลักที่เราเทียบ
Agent Skillsกฎชุดเดียวกัน แยกเป็น 4 ชุดคู่หลักที่เราเทียบ
Skills แบบอ่านทุกครั้งข้อความของ Skills รวมเป็นไฟล์เดียวดูว่าการเปิดอ่านทีละชุดมีผลไหม

ทุกกลุ่มเป็น AI ตัวเดียวกัน (Claude Sonnet 5 ผ่าน Claude Code) ต่างกันแค่วิธีให้กฎ

กฎ 20 ข้อแตกเป็นสิ่งที่ต้องทำหรือห้ามทำได้ 47 ข้อ เท่ากันทั้งไฟล์เดียวและ Skills เกณฑ์ตัดสินล็อกไว้ก่อนเก็บข้อมูล

[คนที่ 1, 0:50] แล้วเราเทียบยังไงครับ ในการทดลองชุดที่ 3 ซึ่งเป็นชุดที่ใช้ตอบคำถาม เราแบ่ง AI เป็น 4 กลุ่ม ทุกกลุ่มเป็น AI ตัวเดียวกัน คือ Claude Sonnet 5 ผ่าน Claude Code ต่างกันแค่วิธีให้กฎ กลุ่มแรก ไม่มีกฎเลย ไว้เป็นจุดเริ่มต้นเทียบ กลุ่มที่สอง ไฟล์เดียว กลุ่มที่สาม Agent Skills สองกลุ่มนี้คือคู่หลักที่เราอยากรู้ กลุ่มที่สี่ Skills แบบอ่านทุกครั้ง คือเอาข้อความของ Skills ทั้ง 4 ชุดมาต่อเป็นไฟล์เดียวให้อ่านทุกครั้ง เนื้อหาเหมือน Skills ทุกตัวอักษร ต่างแค่ไม่ได้เปิดทีละชุด ไว้ดูว่าถ้า Skills ดีกว่า ดีเพราะวิธีเปิดอ่าน หรือเพราะถ้อยคำที่เขียน กฎ 20 ข้อแตกออกมาเป็นสิ่งที่ต้องทำหรือห้ามทำได้ 47 ข้อ ไฟล์เดียวกับ Skills มีครบเท่ากัน และเกณฑ์ตัดสินผล เราล็อกไว้ก่อนเก็บข้อมูล ไม่ปรับทีหลังครับ
