เราเทียบ 4 กลุ่ม คู่หลักได้กฎ 20 ข้อชุดเดียวกัน ต่างกันแค่ส่งเป็นไฟล์เดียวหรือเป็น Skills

ไฟล์เดียวกฎ 20 ข้อในไฟล์เดียวคำถามหลัก
Agent Skillsกฎชุดเดียวกัน แบ่งเป็น skillคำถามหลัก
Skills แบบอ่านทุกครั้งข้อความของ Skills รวมเป็นไฟล์เดียวการเปิดอ่านทีละชุดมีผลไหม

กฎ 20 ข้อนี้แตกเป็นสิ่งที่ต้องทำหรือห้ามทำได้ 47 อย่าง ทั้งสองแบบมีครบเท่ากัน ก่อนเริ่มเราเขียนไว้บน GitHub ว่าผลออกได้สามทาง คือ ต่างกัน เทียบเท่า หรือสรุปไม่ได้

[คนที่ 1, 1:00] คำถามหลักคือ ถ้าให้กฎชุดเดียวกัน 20 ข้อ แตกออกมาเป็นสิ่งที่ต้องทำหรือห้ามทำได้ 47 อย่างเท่ากันทุกอย่าง แต่ส่งแบบ Skills กับแบบไฟล์เดียว AI จะทำตามกฎต่างกันไหม เราตั้งไว้ 4 กลุ่ม กลุ่มแรกไม่มีกฎเลย ไว้เป็นจุดเริ่มต้นเทียบ ไฟล์เดียวกับ Skills คือคู่หลัก ส่วนกลุ่มสุดท้ายเอาข้อความของ Skills มารวมเป็นไฟล์เดียวให้อ่านทุกครั้ง ไว้ดูว่าถ้าต่าง ต่างเพราะวิธีเปิดอ่านทีละชุด หรือเพราะถ้อยคำ และสำคัญคือ เราเขียนเกณฑ์ตัดสินไว้ก่อนเก็บข้อมูล ล็อกไว้บน GitHub ว่าผลจะออกได้สามทาง คือ ต่างกัน เทียบเท่า หรือสรุปไม่ได้ ตัดสินตามนั้น ไม่ปรับทีหลัง
