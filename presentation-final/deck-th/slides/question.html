คำถามของเรา: กฎชุดเดียวกัน เขียนสองแบบนี้
AI ทำตามต่างกันไหม

กลุ่ม AIได้กฎแบบไหนมีไว้ทำอะไร
ไม่มีกฎไม่ได้กฎเลยจุดเริ่มต้นไว้เทียบ
ไฟล์เดียวกฎ 20 ข้อในไฟล์เดียวคู่หลักที่เราเทียบ
Agent Skillsกฎชุดเดียวกัน แยกเป็น 4 ชุดคู่หลักที่เราเทียบ
Skills แบบอ่านทุกครั้งข้อความของ Skills รวมเป็นไฟล์เดียวดูว่าการเปิดอ่านทีละชุดมีผลไหม

ทุกกลุ่มเป็น AI ตัวเดียวกัน (Claude Sonnet 5 ผ่าน Claude Code) ต่างกันแค่วิธีให้กฎ

กฎ 20 ข้อแตกเป็นสิ่งที่ต้องทำหรือห้ามทำได้ 47 ข้อ เท่ากันทั้งไฟล์เดียวและ Skills เกณฑ์ตัดสินล็อกไว้ก่อนเก็บข้อมูล

[คนที่ 1, 1:00] คำถามวิจัยของเราคือ ถ้าให้กฎชุดเดียวกัน แต่เขียนเป็นสองแบบนี้ AI จะทำตามกฎได้ต่างกันไหม เราแบ่ง AI เป็น 4 กลุ่ม ทุกกลุ่มเป็น AI ตัวเดียวกัน คือ Claude Sonnet 5 ที่ทำงานผ่าน Claude Code ต่างกันแค่วิธีที่ได้รับกฎ กลุ่มแรกไม่ได้รับกฎเลย ใช้เป็นจุดเริ่มต้นว่าถ้าไม่มีกฎ AI ทำได้แค่ไหน กลุ่มไฟล์เดียวกับกลุ่ม Agent Skills คือคู่หลักที่เราอยากเปรียบเทียบ ส่วนกลุ่มสุดท้ายได้เนื้อหาเดียวกับ Skills ทุกตัวอักษร แต่ให้อ่านทั้งหมดตั้งแต่ต้น ไว้ดูว่าถ้าผลต่างกัน ต่างเพราะวิธีเปิดอ่านทีละชุด หรือเพราะถ้อยคำ เพื่อให้เทียบกันได้อย่างยุติธรรม เราแตกกฎ 20 ข้อออกเป็นสิ่งที่ต้องทำและห้ามทำได้ 47 ข้อ แล้วตรวจว่าไฟล์เดียวกับ Skills มีครบเท่ากันทั้ง 47 ข้อ และก่อนเก็บข้อมูล เราเขียนเกณฑ์ตัดสินไว้ล่วงหน้าแล้วล็อกไว้บน GitHub ว่าผลแบบไหนจะสรุปว่าต่างกัน เทียบเท่า หรือสรุปไม่ได้ จะได้ไม่ปรับเกณฑ์ทีหลังตามผลที่ออกมาครับ
