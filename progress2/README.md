1. **ครั้งที่แล้วยังไม่มีผลเปรียบเทียบเลย ครั้งนี้เก็บครบสองรอบ 396 run** (สไลด์ 1)

   คอขวดคือจำนวนโจทย์ ไม่ใช่เครื่องมือวัด (สไลด์ 5)
3. **ใส่กฎแล้วตามกฎดีขึ้นจริง แต่ทำงานสำเร็จน้อยลง** — น่าสนใจที่สุดที่เจอ
