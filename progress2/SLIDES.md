## สไลด์ 5 — ทำไมยังสรุปไม่ได้ *(สไลด์สำคัญที่สุด)*

```
วิธีทดสอบนับ " โจทย์ " เป็นหน่วย  ไม่ใช่ run
โจทย์ที่สองกลุ่มได้เท่ากัน = ไม่ให้ข้อมูลเลย

          โจทย์ที่ให้ข้อมูล      p ต่ำสุดที่เป็นไปได้
รอบที่ 1        5 / 11                0.0625
รอบที่ 2        5 / 11                0.0625     ← เท่าเดิม

เกณฑ์ที่ต้องผ่าน = 0.05
```

**0.0625 > 0.05 แปลว่านัยสำคัญเป็นไปไม่ได้ตั้งแต่ก่อนเห็นข้อมูล ทั้งสองรอบ**
ต่อให้ผลจริงชัดแค่ไหนก็ไม่ผ่าน

**การซ่อมตัวชี้วัดช่วยจริง แต่ช่วยคนละเรื่อง** — มันทำให้ผลคมขึ้น
(p 0.500 → 0.250 · ขอบล่าง −6.8 → −2.1) แต่ไม่ได้เพิ่มจำนวนโจทย์

> **คอขวดคือจำนวนโจทย์ ไม่ใช่เครื่องมือวัด — และสองรอบยืนยันตรงกัน**

## สไลด์ 7 — เรื่องที่เจอระหว่างเก็บข้อมูล

ระบบตรวจสภาพทุก run จับของแปลกได้ 3 เรื่องที่ไม่ได้คาดไว้

1. **ชุด skill ที่ติดมากับเครื่องมือเปลี่ยนเอง** 18 → 15 → 18 โดยเราไม่ได้ทำอะไร

3. **AI เขียนไฟล์ออกไปนอกพื้นที่ทดลอง** — ไฟล์หนึ่งสรุปกฎของกลุ่มตัวเอง
   อีกไฟล์เป็นเฉลยโจทย์ข้อที่ยากที่สุด **ถ้า run ถัดไปได้อ่าน การทดลองพังทันที**

**จับได้และหยุดทันทีทั้งสามเรื่อง ไม่มี run ปนเปื้อนเข้าชุดข้อมูลเลย**
