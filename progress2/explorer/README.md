# หน้าเปิดคุยกับอาจารย์ — เปิดของจริงให้ดูได้

**เปิดด้วยการดับเบิลคลิก `index.html`** ไม่ต้องมีเน็ต ไม่ต้องล็อกอิน ไม่ต้องรัน server

> ⚠️ **`index.html` กับ `data.js` ต้องอยู่ด้วยกันเสมอ** ถ้าย้ายให้ย้ายทั้งโฟลเดอร์

## ต่างจาก PDF ยังไง

| | `canva/deck-round2.pdf` | โฟลเดอร์นี้ |
|---|---|---|
| ใช้เมื่อ | ฉายขึ้นจอ เดินตามลำดับ | **นั่งคุยหน้าจอเดียวกัน อาจารย์อยากเจาะตรงไหนก็เปิดได้** |
| เจาะลงได้ไหม | ไม่ได้ | ได้ — กฎจริงของทุกกลุ่ม · โจทย์ทุกข้อ · run ทุกตัวพร้อมผลตรวจกฎทีละข้อ |
| พังได้ไหม | แทบไม่ | ถ้าเบราว์เซอร์มีปัญหา **ให้กลับไปใช้ PDF** |

**PDF ยังเป็นตัวสำรองเสมอ** เนื้อหาตรงกัน

## สามอย่างที่เปิดให้ดูได้ ซึ่ง PDF ทำไม่ได้

1. **กฎที่ส่งให้เอเจนต์** — ข้อความจริงของ A1 · A2 · A5 ทั้งไฟล์ ไม่ได้ย่อ
   พร้อมป้ายว่าไฟล์ไหนโหลดตลอดเวลา ไฟล์ไหนโหลดเมื่อเข้าเงื่อนไข
2. **โจทย์ทั้ง 11 ข้อ** — กฎของแต่ละข้อ และ `RCRc` รายรอบของทุกกลุ่ม คลิกตัวเลขเพื่อเปิด run นั้น
3. **run ทุกตัว** — กรองตามกลุ่มหรือโจทย์ คลิกแล้วเห็นผลตรวจกฎวิกฤตทีละข้อ
   ว่าข้อไหนผ่าน ข้อไหนตก ข้อไหนไม่เข้าเงื่อนไข · และคำสั่งจริงที่ใช้เก็บกับวิเคราะห์ข้อมูล

## ตัวเลขมาจากไหน

`data.js` สร้างจากข้อมูลจริงด้วย

```bash
node slides-images/src/make-explorer-data.mjs
```

อ่านจาก `results/` · `results-study2/` · `arms/**` · `scenarios/*.json`
**ไม่มีตัวเลขที่พิมพ์ด้วยมือในหน้านี้แม้แต่ตัวเดียว** ค่าอย่าง m · เพดาน p · สัดส่วนที่มีเฉด
คำนวณสดในหน้าเว็บจาก run ดิบ แล้วออกมาตรงกับ `numbers.json` ซึ่งเป็นการตรวจสอบตัวเองไปในตัว
