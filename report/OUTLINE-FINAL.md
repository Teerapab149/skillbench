(ที่มาและความสำคัญ เป็นเนื้อความใต้หัวข้อ 1. โดยตรง ไม่มีเลขย่อย ตาม template และ BIS2-11 — เอเจนต์เขียนโค้ดต้องทำตามกฎองค์กร; สองวิธีส่งกฎ: Context Engineering กับ Agent Skills)
1.1. วัตถุประสงค์ (1.1.1.–1.1.3.)
1.2. คำถามวิจัยและสมมติฐาน — A2 vs A1 (ผลหลัก, ตารางตัดสินสามทาง ±0.125) · A2 vs A5 (ผลรองหลัก)
1.3. ขอบเขต — โมเดลเดียว, ภาษาไทย, ระบบจำลองเดียว, 22 โจทย์
1.4. ประโยชน์ที่คาดว่าจะได้รับ (1.4.1.–)

## 2. แนวคิดและงานที่เกี่ยวข้อง (~7 หน้า) ← `ch2` ย่อ
2.1 Context Engineering และ Agent Skills (progressive disclosure)
2.2 การประเมิน LLM ในงานพัฒนาซอฟต์แวร์ และการวัดการทำตามคำสั่ง
2.3 ลำดับชั้นคำสั่ง ความยาว context และความสุ่มของโมเดล
2.4 RTM ในบทบาทเครื่องมือวัด
2.5 การทดลองแบบมีกลุ่มควบคุมและการประกาศแผนล่วงหน้า
2.6 งานในวิชานี้ที่ใกล้เคียง (BIS1-07 Context Engineering เชิงคุณภาพ) และช่องว่างที่งานนี้เติม
> ⛔ 6 จุดในบทที่ 2 เดิม: ผู้วิจัยตรวจกับต้นฉบับก่อนใส่

## 3. การออกแบบการทดลอง (~9 หน้า) ← `ch3` เขียนใหม่รอบชุดที่ 3
3.1 กรอบแนวคิด ตัวแปรต้น/ตาม (รูปที่ 1)
3.2 กลุ่มทดลอง A0 A1 A2 A5 และความเท่าเทียมของเนื้อหากฎ
3.3 ระบบจำลองจองการ์ดจอ (event sourcing) และโจทย์ 22 ข้อ 5 ตระกูลกับดัก + คู่คำกระตุ้น 3 คู่ (ตาราง)
3.4 รอบตอบกลับ (follow-up) และการวัดสองจังหวะ (รอบแรก/หลังตอบกลับ)
3.5 ตัวชี้วัด RCRc และสูตร
3.6 สถิติ: sign-flip ระดับโจทย์, CI จากการกลับด้าน, ตารางตัดสินสามทาง, fixed-sequence
3.7 การประกาศแผนล่วงหน้า (tag `study3-prereg`), กฎจำนวนรอบตามเวลา, การทำ pilot 4 รอบ
3.8 เส้นทางสู่ชุดที่ 3: ชุดที่ 1–2 สอนอะไร (ตารางสั้น — รายละเอียดภาคผนวก)

## 4. ระบบวัดผลและการตรวจเครื่องมือวัด (~7 หน้า) ← `ch4` ย่อ
4.1 สถาปัตยกรรม (รูปที่ 2: หนึ่ง run)
4.2 การติดตั้งบริบทและการตรวจว่าเข้าบริบทจริง (manipulation check)
4.3 ตัวตรวจกฎแบบกำหนดผลได้ + ด่านยอมรับ 5 ด่าน
4.4 ทำไมระบบวัดเอเจนต์ล้มเหลวแบบเงียบ — ตัวอย่างข้อบกพร่องที่จับได้ (ชุดที่ 2 → 3)
4.5 การคุมตัวแปร: manifest, memory quarantine, fixture reset, attempt provenance

## 5. ผลการทดลอง (~10 หน้า) ← `ch5c` (สร้างจากสคริปต์) + บรรยาย
5.1 ชุดข้อมูล: 264 run, 3 รอบ, ส่วนเบี่ยงเบน D1–D6 (ตารางสั้น)
5.2 ผลหลัก A2 vs A1 → **เทียบเท่า** (ตาราง + รูปช่วงความเชื่อมั่นเทียบเกณฑ์)
5.3 การวิเคราะห์ความไว SA-1 / SA-2 (ตาราง)
5.4 ผลรองหลัก A2 vs A5 (ค่าประมาณ ประตูปิด)
5.5 ตัวชี้วัดรายกลุ่ม: CRIT, RCR, SCOPE, TASK, ต้นทุน (ตาราง + รูป A0 เทียบกลุ่มที่มีกฎ — เชิงสำรวจ)
5.6 ผลรอบแรกและการกู้คืนหลังรอบตอบกลับ
5.7 การเรียก skill (Trigger F1) และ manipulation check
5.8 ผลชุดที่ 1–2 โดยสรุป (เพื่อเทียบ)

## 6. อภิปรายผลและข้อจำกัด (~7 หน้า) ← `ch6` เขียนใหม่ ย่อจาก 80 KB
6.1 "มีกฎ" ต่างกันมาก "วิธีส่งกฎ" ไม่ต่าง — ตีความ
6.2 ทำไมชุดที่ 3 สรุปได้แต่ชุดที่ 1–2 ไม่ได้ (เครื่องมือวัด ไม่ใช่โชค)
6.3 ข้อเสนอแนะเชิงปฏิบัติสำหรับคนเขียนกฎให้เอเจนต์
6.4 ข้อจำกัด: เพดานคะแนน, โมเดลเดียว/ภาษาเดียว, ผู้วิจัยออกแบบทั้งกฎและตัวตรวจ, ตัวตรวจที่บกพร่อง 3 จุด, 3 รอบแทน 4, เวลาระบบจำลองตรึง
