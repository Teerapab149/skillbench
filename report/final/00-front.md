รายงานฉบับนี้เป็นส่วนหนึ่งของรายวิชา 477-401 สัมมนาระบบสารสนเทศทางธุรกิจ จัดทำขึ้นเพื่อศึกษาว่า การเขียนกฎให้เอเจนต์เขียนโค้ดในรูปแบบ Agent Skills ทำให้เอเจนต์ปฏิบัติตามกฎได้ต่างจากการเขียนกฎไว้ในไฟล์เดียวหรือไม่ เนื้อหาครอบคลุมแนวคิดที่เกี่ยวข้อง การออกแบบการทดลอง ระบบวัดผลที่ผู้จัดทำพัฒนาขึ้น ผลการทดลอง การอภิปรายผล และข้อเสนอแนะสำหรับทีมพัฒนาที่นำเอเจนต์ไปใช้งาน

งานนี้ทดลองสามชุด สองชุดแรกให้ผลที่สรุปไม่ได้ แต่ทำให้พบข้อบกพร่องของเครื่องมือวัดที่ต้องแก้ ชุดที่สามจึงออกแบบใหม่ ประกาศแผนการวิเคราะห์ไว้ล่วงหน้า และได้ข้อสรุปที่ตอบคำถามวิจัยได้ ผู้จัดทำรายงานส่วนเบี่ยงเบนจากแผนทุกข้อไว้ในเล่ม และเปิดเผยโค้ด ข้อมูล และประวัติการแก้ไขทั้งหมดไว้ใน repository ของโครงการ เพื่อให้ผู้อ่านตรวจสอบและทำซ้ำได้

งานนี้เกี่ยวข้องกับปัญญาประดิษฐ์สองบทบาทที่แยกจากกัน บทบาทแรกคือ *สิ่งที่ถูกทดลอง* ได้แก่โมเดล Claude Sonnet 5 ที่ทำงานผ่าน Claude Code ในการทดลองทั้ง 264 run บทบาทที่สองคือ *เครื่องมือช่วยผู้จัดทำ* ผู้จัดทำใช้ Claude (Anthropic) ช่วยพัฒนาโค้ดของระบบวัดผล ช่วยวิเคราะห์ข้อมูล ช่วยตรวจทานแผนการทดลอง และช่วยเรียบเรียงร่างของรายงานฉบับนี้ ผู้จัดทำเป็นผู้กำหนดคำถามวิจัย ตัดสินใจเรื่องการออกแบบและการวิเคราะห์ ตรวจผลและข้อความทั้งหมด และรับผิดชอบต่อเนื้อหาของรายงาน ข้อเท็จจริงที่ว่าผู้ช่วยเป็นโมเดลตระกูลเดียวกับที่ถูกทดลอง ได้ระบุไว้เป็นข้อจำกัดในหัวข้อ 6.4.

ผู้จัดทำขอขอบพระคุณ ผู้ช่วยศาสตราจารย์ ดร.รุชดี บิลหมัด อาจารย์ที่ปรึกษา ที่ให้คำแนะนำตลอดการทำงาน และหวังว่ารายงานฉบับนี้จะเป็นประโยชน์ต่อผู้ที่สนใจการนำเอเจนต์ปัญญาประดิษฐ์ไปใช้ในงานพัฒนาระบบ

**คำถาม** ทีมพัฒนาที่ใช้ AI ช่วยเขียนโค้ด (เอเจนต์) ต้องบอกกติกาของทีมให้มันรู้ เช่น แก้เฉพาะส่วนที่สั่ง ห้ามลบข้อมูล และต้องตรวจผลกระทบก่อนแก้ส่วนที่คิดเงิน วิธีบอกกติกามีสองแบบหลัก แบบแรกคือเขียนทุกข้อไว้ในไฟล์เดียวที่ AI อ่านทุกครั้ง แบบที่สองคือ Agent Skills ซึ่งแยกกติกาเป็นชุดย่อย ให้ AI เปิดอ่านเฉพาะชุดที่เกี่ยวกับงานตรงหน้า งานนี้ถามว่าสองแบบนี้ทำให้ AI ทำตามกติกาได้ต่างกันหรือไม่

**วิธีทดลอง** ผู้จัดทำสร้างระบบจองเครื่อง GPU จำลอง และโจทย์ 22 ข้อที่แต่ละข้อมีกับดัก เช่น คอมเมนต์ในโค้ดที่สั่งให้ทำสิ่งที่ผู้ใช้ไม่ได้ขอ หรือการแก้ที่ทำให้ใบแจ้งหนี้เดือนก่อนเปลี่ยนไปเงียบ ๆ แล้วให้ AI ตัวเดียวกันทำโจทย์ภายใต้ 4 เงื่อนไข ได้แก่ ไม่มีกติกา · กติกาไฟล์เดียว · Agent Skills · และข้อความเดียวกับ Agent Skills แต่ให้อ่านตลอดเวลา รวม 264 ครั้ง ทุกครั้งให้คะแนนด้วยโปรแกรมจากสิ่งที่ AI ทำจริง ไม่ใช้คนหรือ AI อีกตัวตัดสิน และล็อกวิธีวิเคราะห์ไว้บน GitHub ก่อนเริ่มเก็บข้อมูล

**ผลที่พบ**

1. **การมีกติกาสำคัญที่สุด** AI ที่ไม่ได้รับกติกาทำงานเสร็จได้เกือบเท่ากัน แต่ทำถูกกติกาสำคัญครบเพียงราวครึ่งหนึ่งของครั้ง เทียบกับราวสี่ในห้าเมื่อได้รับกติกา และแก้ไฟล์นอกขอบเขตหรือทำให้ข้อมูลย้อนหลังเปลี่ยนบ่อยกว่าหลายเท่า (เปรียบเทียบเชิงสำรวจ)
2. **รูปแบบของกติกาไม่ทำให้ต่างกันเกินเกณฑ์** Agent Skills ได้คะแนนสูงกว่าไฟล์เดียว 2.8 จุดจาก 100 ซึ่งน้อยกว่าเกณฑ์ "ต่างอย่างมีความหมาย" ที่ตั้งไว้ล่วงหน้า (12.5 จุด หรือราวการพลาดกติกาสำคัญหนึ่งข้อต่องาน) จึงสรุปได้ว่า *เทียบเท่า* และเมื่อดูเฉพาะงานที่ทำเสร็จ สองแบบทำตามกติกาได้แทบเท่ากันทุกประการ
3. **Agent Skills ประหยัดกว่าเล็กน้อย** ใช้ต้นทุนต่ำกว่าราว 10% และเร็วกว่าราว 30 วินาทีต่องาน ในการทดลองนี้
4. **ยังตอบไม่ได้ว่ากลไก "เปิดอ่านเฉพาะที่ใช้" มีผลหรือไม่** เพราะตามแผนที่ล็อกไว้ การเปรียบเทียบนั้นทดสอบได้เฉพาะเมื่อผลข้อ 2 พบความต่าง

**ข้อเสนอแนะ** ทีมพัฒนาควรลงแรงกับการเขียนกติกาที่ดีก่อน แล้วเลือกรูปแบบตามความสะดวกในการดูแลและต้นทุน ถ้าใช้ Agent Skills ควรตรวจว่าคำอธิบายของแต่ละชุดทำให้ AI เปิดอ่านถูกงาน และควรเปิดช่องให้ AI ถามได้เมื่อเจอข้อกำหนดที่ไม่ชัด

**ขอบเขต** ผลนี้มาจาก AI รุ่นเดียว (Claude Sonnet 5) คำสั่งภาษาไทย ระบบจำลองหนึ่งระบบ และกติกายาวราว 2,000–3,300 token ยังไม่ควรนำไปใช้กับเงื่อนไขที่ต่างออกไปมากโดยไม่ทดสอบซ้ำ
