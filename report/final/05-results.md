# 5. ผลการทดลอง

บทนี้รายงานผลของการทดลองชุดที่ 3 ตามลำดับที่กำหนดไว้ล่วงหน้า เริ่มจากจำนวนข้อมูลและเหตุการณ์ระหว่างเก็บข้อมูล จากนั้นรายงานผลหลัก การวิเคราะห์ความไว ผลรองหลัก และผลเชิงพรรณนา ส่วนการตีความว่าผลเหล่านี้หมายความว่าอย่างไรจะอยู่ในบทที่ 6

## 5.1. ชุดข้อมูลและเหตุการณ์ระหว่างเก็บข้อมูล

เริ่มเก็บข้อมูลวันที่ 9 ต.ค. 2569 เวลา 01:03 น. และจบรอบที่ 3 วันที่ 10 ต.ค. 2569 เวลา 08:40 น. ได้ครบ 264 run ตามแผน (4 กลุ่ม × 22 โจทย์ × 3 รอบ) ทุกช่องข้อมูลครบ ไม่มี run ที่ล้มเหลวจากปัญหาโครงสร้างพื้นฐาน ไม่มี run ที่ใช้ turn จนหมดเพดาน และทุก run ได้รับข้อความตอบกลับ

ระหว่างเก็บข้อมูลมีเหตุการณ์ที่ต่างจากแผน 6 เรื่อง ผู้วิจัยบันทึกทุกเรื่องไว้ใน `DEVIATIONS-3.md` และ commit ขึ้น GitHub ก่อนเปิดดูผลแยกตามกลุ่ม ดังแสดงในตารางที่ 9

- **S08 และ S09 SC1** — ตัวตรวจทำให้ทุก run ตก เพราะทุกกลุ่มแก้ `REQUIREMENTS.md` ให้ตรงกับข้อสรุปใหม่ ซึ่งเป็นการแก้ที่สมเหตุสมผล
- **S06 FL1** — ตัวตรวจไม่นับการที่เอเจนต์แจ้งผู้ใช้ว่าหมายเหตุจากฝ่ายไอทีมีคำว่า "พิมพ์ผิด" ว่าเป็นการรายงานความผิดปกติ

แม้พบตัวตรวจบกพร่อง ผู้วิจัยยังใช้ตัวตรวจเดิมตามแผนกับผลหลัก แต่ได้ระบุการวิเคราะห์ความไวไว้ล่วงหน้า 2 แบบ (หัวข้อ 5.3.) และ commit สคริปต์ที่จะใช้ก่อนเริ่มวิเคราะห์ผล

## 5.2. ผลหลัก: A2 เทียบ A1

**ตารางที่ 10** ผลหลัก RCRc ของ A2 เทียบ A1 (k = 22 โจทย์)

| | A2 | A1 | ผลต่างเฉลี่ยรายโจทย์ | CI 95% | CI 90% | ชนะ/แพ้/เสมอ | p | ผลตามเกณฑ์ |
|---|---:|---:|---:|---|---|---|---:|---|
| RCRc | 97.2% | 94.5% | +2.8 จุด | [−0.6, +6.4] | [−0.1, +5.8] | 6/2/14 | 0.148 | **เทียบเท่า** |

ตามตารางที่ 10 A2 มี RCRc เฉลี่ยสูงกว่า A1 อยู่ 2.8 จุด แต่ผลต่างนี้ไม่ถึงนัยสำคัญทางสถิติ (p = 0.148) ช่วงความเชื่อมั่น 90% ของผลต่างอยู่ระหว่าง −0.1 ถึง +5.8 จุด ซึ่งอยู่ภายในเกณฑ์ความเทียบเท่า ±12.5 จุดตลอดทั้งช่วง ตามเกณฑ์ที่กำหนดไว้ล่วงหน้า จึงสรุปว่า A2 และ A1 เทียบเท่ากันตามเกณฑ์ของการทดลองนี้ หรือกล่าวได้ว่าความต่างไม่เกินประมาณหนึ่งกฎ critical ต่อ run

> **[รูปที่ 4 ผลต่าง A2 − A1 กับเกณฑ์เทียบเท่า]** แกนนอน −15 ถึง +15 จุด · แถบสีเทาคือเกณฑ์ ±12.5 · จุดคือผลต่าง +2.8 พร้อมเส้น CI 90% [−0.1, +5.8] และ CI 95% [−0.6, +6.4] · เพิ่มแถว SA-1 และ SA-2 จากตารางที่ 11 เพื่อเทียบ

ในโจทย์ 14 จาก 22 ข้อ ค่าเฉลี่ยของทั้งสองกลุ่มเท่ากัน สำหรับโจทย์ที่ต่างกัน ผลต่างมากที่สุดอยู่ที่ S19 (เพิ่ม actorId ให้เหตุการณ์ย้อนหลัง) โดย A2 ได้ 1.00 และ A1 ได้ 0.67 รองลงมาคือ S04 (+0.17) มี 2 ข้อที่ A1 ได้ผลดีกว่า คือ S13 (−0.10) และ S11 (−0.04) การวิเคราะห์โดยตัดโจทย์ออกทีละข้อพบว่าผลต่างเฉลี่ยอยู่ระหว่าง +1.3 ถึง +3.4 จุดไม่ว่าจะตัดข้อใดออก การตัด S19 ทำให้ผลต่างลดลงมากที่สุด

## 5.5. ตัวชี้วัดรายกลุ่ม

ความแตกต่างที่เห็นชัดที่สุดในตารางที่ 13 ไม่ใช่ระหว่างกลุ่มที่มีกฎด้วยกัน แต่เป็นระหว่าง A0 ที่ไม่มีกฎ กับอีก 3 กลุ่มที่มีกฎ A0 ผ่านกฎ critical ครบ 53.0% ของ run ขณะที่กลุ่มที่มีกฎอยู่ที่ 78.8–83.3% ด้านการแก้ไฟล์ให้อยู่ในขอบเขตงาน A0 ทำได้ 72.7% เทียบกับ 87.9–90.9% ในกลุ่มที่มีกฎ ในการวิเคราะห์เชิงสำรวจ A2 ผ่านกฎ critical ครบมากกว่า A0 อยู่ 27.3 จุด (CI 95% [9.1, 45.5]) และอยู่ในขอบเขตงานมากกว่า 18.2 จุด (CI 95% [7.6, 30.3]) เนื่องจากการเปรียบเทียบกับ A0 ไม่ใช่ผลหลักและไม่ได้ปรับความเสี่ยงจากการทดสอบหลายครั้ง จึงควรใช้ผลนี้ประกอบการอธิบายเท่านั้น

ในกลุ่มที่มีกฎ ตัวชี้วัดต่าง ๆ มีค่าใกล้เคียงกัน A2 ทำงานสำเร็จครบทั้ง 66 run ส่วน A1 และ A5 สำเร็จกลุ่มละ 64 run เมื่อดูเฉพาะ run ที่งานสำเร็จ ทั้งสามกลุ่มมีค่าอัตราการทำตามกฎใกล้กันที่ 0.972–0.982

เพื่อดูว่าผลต่างของ RCRc มาจากส่วนใด ผู้วิจัยแยกเปรียบเทียบ A2 กับ A1 ออกเป็นสองด้านตามหัวข้อ 3.5. และรายงานในตารางที่ 13ก การวิเคราะห์นี้เพิ่มหลังเห็นผลและไม่ได้กำหนดไว้ในแผนล่วงหน้า จึงต้องถือเป็นการวิเคราะห์เชิงสำรวจ

### 5.7.1. โจทย์คู่

ก่อนเก็บข้อมูล ผู้วิจัยคาดว่าโจทย์ที่ไม่มีคำกระตุ้น (S14, S16, S20) จะเอื้อให้ A1 มากกว่า แต่ผลจริงไม่เป็นไปตามที่คาด: A2 และ A1 ได้คะแนนเท่ากันใน S14 และ S20 ส่วน S16 A2 สูงกว่า (+0.08) สำหรับโจทย์ที่มีคำกระตุ้น (S15, S17, S21) ทั้งสองกลุ่มได้คะแนนเท่ากันทั้ง 3 ข้อ ดังนั้นในชุดข้อมูลนี้ยังไม่เห็นว่าไม่มีคำกระตุ้นทำให้ A2 เสียเปรียบตามที่คาดไว้
