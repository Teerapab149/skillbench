# 5. ผลการทดลอง

บทนี้รายงานผลของการทดลองชุดที่ 3 ตามลำดับที่ประกาศไว้ล่วงหน้า เริ่มจากชุดข้อมูลและเหตุการณ์ระหว่างเก็บ ผลหลัก การวิเคราะห์ความไว ผลรองหลัก แล้วจึงเป็นผลเชิงพรรณนา ส่วนการตีความทั้งหมดอยู่ในบทที่ 6

## 5.1. ชุดข้อมูลและเหตุการณ์ระหว่างเก็บข้อมูล

การเก็บข้อมูลเริ่มวันที่ 9 ต.ค. 2569 เวลา 01:03 น. และครบรอบที่ 3 วันที่ 10 ต.ค. 2569 เวลา 08:40 น. ได้ข้อมูล 264 run ครบทุกช่อง (4 กลุ่ม × 22 โจทย์ × 3 รอบ) ไม่มี run ที่ล้มเหลวเพราะโครงสร้างพื้นฐาน ไม่มี run ที่ใช้ turn จนหมดเพดาน และทุก run ได้รับรอบตอบกลับ

ระหว่างเก็บข้อมูลมีเหตุการณ์ที่ต่างจากแผน 6 เรื่อง ผู้วิจัยบันทึกทุกเรื่องในเอกสาร `DEVIATIONS-3.md` และ commit ขึ้น GitHub ก่อนดูผลแยกกลุ่ม ดังตารางที่ 9

**ตารางที่ 9** ส่วนเบี่ยงเบนจากแผนระหว่างเก็บข้อมูล

| รหัส | เหตุการณ์ | ผลต่อข้อมูล |

- **S05 GP1** จับชื่อ error อย่าง `CANCELLATION_TOO_LATE` ว่าเป็นการทำกฎยกเลิกก่อน 2 ชั่วโมง ทั้งที่เป็นเพียงเงื่อนไข "ยกเลิกไม่ได้หลังเวลาเริ่ม" (รวมทุกกลุ่ม ตก 6 จาก 8 run ที่ตรวจ ในจำนวนนี้อย่างน้อย 4 run เป็นการจับผิด)
- **S08 และ S09 SC1** ตกทุก run เพราะเอเจนต์ทุกกลุ่มแก้ `REQUIREMENTS.md` ให้ตรงกับมติใหม่ ซึ่งสมเหตุสมผล
- **S06 FL1** ไม่นับเอเจนต์ที่รายงานหมายเหตุ "พิมพ์ผิด" ของฝ่ายไอทีให้ผู้ใช้ทราบ ว่าเป็นการแจ้งความผิดปกติ

ผลหลักยังใช้ตัวตรวจเดิมตามแผน แต่ผู้วิจัยประกาศการวิเคราะห์ความไวสองแบบไว้ล่วงหน้า (หัวข้อ 5.3.) และ commit สคริปต์ก่อนรันการวิเคราะห์ครั้งแรก

## 5.2. ผลหลัก: A2 เทียบ A1

**ตารางที่ 10** ผลหลัก RCRc ของ A2 เทียบ A1 (k = 22 โจทย์)

| | A2 | A1 | ผลต่างเฉลี่ยรายโจทย์ | CI 95% | CI 90% | ชนะ/แพ้/เสมอ | p | ผลตามเกณฑ์ |
|---|---:|---:|---:|---|---|---|---:|---|
| RCRc | 97.2% | 94.5% | +2.8 จุด | [−0.6, +6.4] | [−0.1, +5.8] | 6/2/14 | 0.148 | **เทียบเท่า** |

ตารางที่ 10 แสดงว่า A2 ได้ RCRc เฉลี่ยสูงกว่า A1 2.8 จุด แต่ไม่ถึงนัยสำคัญ (p = 0.148) ช่วงความเชื่อมั่น 90% ของผลต่างอยู่ระหว่าง −0.1 ถึง +5.8 จุด ซึ่งอยู่ภายในเกณฑ์เทียบเท่า ±12.5 จุดทั้งช่วง ตามตารางตัดสินที่ประกาศไว้ ผลหลักจึงเป็น **"เทียบเท่า"** แปลว่าการส่งกฎแบบ Agent Skills กับแบบไฟล์เดียว ให้ผลต่างกันไม่เกินราวหนึ่งกฎ critical ต่อ run

> **[รูปที่ 4 ผลต่าง A2 − A1 กับเกณฑ์เทียบเท่า]** แกนนอน −15 ถึง +15 จุด · แถบสีเทาคือเกณฑ์ ±12.5 · จุดคือผลต่าง +2.8 พร้อมเส้น CI 90% [−0.1, +5.8] และ CI 95% [−0.6, +6.4] · เพิ่มแถว SA-1 และ SA-2 จากตารางที่ 11 เพื่อเทียบ

โจทย์ 14 จาก 22 ข้อได้ค่าเฉลี่ยเท่ากันทั้งสองกลุ่ม ส่วนที่ต่างกัน ผลต่างที่ใหญ่ที่สุดอยู่ที่ S19 (เติม actorId ให้เหตุการณ์ย้อนหลัง) ซึ่ง A2 ได้ 1.00 และ A1 ได้ 0.67 รองลงมาคือ S04 (+0.17) ฝั่งที่ A1 ดีกว่ามีสองข้อ คือ S13 (−0.10) และ S11 (−0.04) การวิเคราะห์อิทธิพลแบบตัดทีละโจทย์พบว่าผลต่างเฉลี่ยอยู่ระหว่าง +1.3 ถึง +3.4 จุดไม่ว่าจะตัดโจทย์ใดออก โดยการตัด S19 ทำให้ผลต่างลดลงมากที่สุด

ระหว่างกลุ่มที่มีกฎ ค่าทุกตัวใกล้กัน A2 ทำงานสำเร็จครบทั้ง 66 run ส่วน A1 และ A5 สำเร็จ 64 run แต่เมื่อดูเฉพาะ run ที่สำเร็จ ทั้งสามกลุ่มทำตามกฎได้ใกล้เคียงกัน (0.972–0.982)

เพื่อแยกผลหลักออกเป็นสองส่วนตามที่อธิบายในหัวข้อ 3.5. ผู้วิจัยเปรียบเทียบ A2 กับ A1 รายโจทย์เพิ่มอีกสองแบบ (ตารางที่ 13ก) การวิเคราะห์นี้ทำหลังเห็นผลและไม่ได้ประกาศไว้ในแผน จึงเป็นเชิงสำรวจ
