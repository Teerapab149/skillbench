# ความพยายามเก็บ rep 0 ครั้งที่ 1 — ล้มทั้งชุดเพราะ OAuth หมดอายุ

12 ก.ย. 2569 · `experimentId: e6e63f12-2dbe-4f34-a086-f12c970243bc` · digest ตอนนั้น `b8e22316f822f605`

## เกิดอะไรขึ้น

`npm run gate0` เดินครบ 55 cell ของ rep 0 แล้วจบด้วย exit 0 เหมือนรันสำเร็จ
แต่ทั้ง 55 run ได้ error เดียวกัน:

```
Failed to authenticate: OAuth session expired and could not be refreshed
```

session หมดอายุระหว่าง `probe-runtime` ที่ผ่านเมื่อ ~20 นาทีก่อน กับตอนเริ่ม `gate0`
CLI คืน `system:init` ตามปกติเพราะเป็นงานฝั่งเครื่อง แต่ข้อความที่ตอบกลับมาเป็น error
`model: "<synthetic>"` และใช้ token 0 — ตรงกับลายเซ็นที่ `claude-cli.mjs` เขียนเตือนตัวเองไว้

## สิ่งที่ระบบทำถูก

- จับเป็น infra error ทั้ง 55 run **ไม่ได้ให้คะแนนว่าเอเจนต์ไม่ทำอะไร** ซึ่งเป็นผลลัพธ์ที่อันตรายกว่า
- **ไม่แช่แข็ง manifest** เพราะการแช่แข็งต้องการ run ที่ไม่ error — ไม่มี manifest ปลอมเกิดขึ้น
- **ไม่ retry** ตาม Amendment 15 ที่ระบุว่า auth ไม่ใช่ความล้มเหลวชั่วคราว
- `--resume` กรอง run ที่ล้มเหลวออกแล้วรันซ่อมให้ — ไม่มี cell ไหนถูกล็อกเป็น error ถาวร

## สิ่งที่ระบบทำผิด และแก้แล้ว

runner **เดินหน้าเผาครบทั้ง 55 cell** ทั้งที่ credential ตายตั้งแต่ run แรก

Amendment 15 ตัดสินว่า auth ห้าม retry แต่ไม่ได้บอกว่าให้ *หยุด* ขณะที่ลิมิตยาว
หยุดทั้งชุดอยู่แล้วด้วยเหตุผลเดียวกันเป๊ะ คือ "การรันต่อมีแต่จะเผา cell ที่เหลือให้กลายเป็น error"

แก้แล้วใน `src/runner.mjs` — `isAuthFailure()` หยุดทั้งชุดตั้งแต่ครั้งแรกที่เจอ
พร้อมบอกวิธีแก้ และบันทึก disposition `auth_failure` ลงสมุด attempt
ตรึงไว้ด้วย `tests/runner-auth-halt.test.mjs` สามข้อ

## ทำไมไฟล์พวกนี้ไม่ใช่ข้อมูล

ทุกแถวมี `error` ไม่มี cell ไหนมีคะแนนที่ใช้ได้ · ไม่มี manifest แช่แข็ง จึงไม่มีหลักฐาน
ว่าเก็บภายใต้สภาพ runtime ใด · และ digest ของการทดลองเปลี่ยนไปแล้วหลังแก้ runner

เก็บไว้เป็นบันทึกว่าเกิดอะไรขึ้นและระบบตอบสนองอย่างไร ไม่ใช่เพื่อนำไปวิเคราะห์
