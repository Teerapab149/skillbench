## ถ้าอยากได้ธีมมืด

ชุดนี้เป็นพื้นอ่อนตัวหนังสือเข้ม ซึ่ง**วางบนสไลด์พื้นมืดก็ยังอ่านออก** เพราะภาพมีพื้นของตัวเอง
แต่ถ้าอยากให้ภาพกลืนไปกับเด็คธีมมืดจริง ๆ ให้สลับค่าสีใน `../src/_fig.css`
**บล็อก `:root` บล็อกเดียว** (อย่างน้อยต้องสลับ `--bg` `--card` `--ink` `--line`)
แล้วเรนเดอร์ใหม่ทั้งชุด ไม่ต้องแก้ไฟล์ภาพทีละไฟล์

## สร้างใหม่

`fig-runs-map.html` และ `fig-effort.html` **ห้ามแก้ด้วยมือ** — สร้างจากข้อมูล

```bash
bash slides-images/src/render-figures.sh
```

สคริปต์นั้นเรียก `fig-runs.gen.mjs` ให้เอง แล้วเรนเดอร์ทุกภาพในชุด
